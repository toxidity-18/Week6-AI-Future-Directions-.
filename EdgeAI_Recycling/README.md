
# **Edge AI Prototype: Recyclable Items Classification**

## **Project Overview**

This project demonstrates an **Edge AI application** by training a lightweight image classification model to recognize recyclable items (plastic, paper, metal, glass). The trained model is converted to **TensorFlow Lite** for deployment on edge devices such as **Raspberry Pi**, enabling **real-time inference** without relying on the cloud.

To make this project lightweight, we use a **synthetic sample dataset** with simple colored shapes representing recyclable items. This is enough for a proof-of-concept and testing the full pipeline.

## **Steps to Run**

### **1. Generate Sample Dataset**

Create a small synthetic dataset for testing:

```bash
python src/generate_sample_data.py
```

* Generates `train` and `val` folders with 10 images per class (plastic, paper, metal, glass).

---

### **2. Train Model**

Train a lightweight CNN model (MobileNetV2) on the sample dataset:

```bash
python src/train_model.py
```

* The model will be saved as `models/recycle_model.h5`
* Training uses data augmentation for better learning.

---

### **3. Convert to TensorFlow Lite**

Convert the trained model for Edge deployment:

```bash
python src/convert_tflite.py
```

* Output: `tflite_models/recycle_model.tflite`
* This TFLite model can run on devices like **Raspberry Pi** or **mobile phones**.

---

### **4. Test TFLite Model**

Run inference on a sample image from the validation set:

```bash
python src/test_model.py
```

* Outputs the predicted class index for the image
* Works offline and demonstrates **real-time Edge AI inference**

---

## **Benefits of Edge AI**

* **Low latency:** Fast predictions without cloud communication
* **Privacy:** Data is processed locally on the device
* **Offline capability:** Works without internet connection
* **Energy-efficient:** Suitable for low-power devices

---

## **Notes**

* The sample dataset is synthetic for demonstration purposes. For real applications, use a larger, real-world dataset like Kaggle’s recyclable items dataset.
* The model can be made smaller or pruned to optimize **inference speed** on low-power Edge devices.
* Make sure file paths match your directory structure, especially on Linux (case-sensitive).
